# Description:
In a team of five students, I helped analyze the customer base of an e-commerce dataset with over 540,000 transactions using unsupervised machine learning. 

We engineered RFM (Recency, Frequency, Monetary) features and segmented customers into four groups, then translated each segment into a behavioral persona to inform a marketing strategy.  From those personas, we developed recommendations on purchasing trends and promotional tactics to grow business. 

I was responsible for data cleaning, preprocessing and for implementing the K-Means clustering model.  I also compared it against Fuzzy C-Means to evaluate how well hard versus soft cluster assignments captured customer behavior.
